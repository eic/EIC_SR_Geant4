## Preparation for the ePIC Monte Carlo Sampling
0) check the git epic branch: epic_synrad_sampling_study_tag25.01.1
1) run ./npsim in the eic-shell enviroment
2) go to ./merge_hepmc and run ./run.bash in a screen session to merge hepmc files into one
3) go to ./hepmc3ascii2root and run ./run.bash - to convert from hepmc3 to root
3) run epic.bash to produce .edm4hep.root and .podio.root files
